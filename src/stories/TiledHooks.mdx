There is no live demo on this page. Unlike the queue-server hooks there is no Tiled simulator, so a
demo would have to reach a real server and would show something different every time you opened it.
To try the hooks against the public demo server, wrap a component in `TiledApiProvider` with
`new TiledApiClient({ baseUrl: 'https://tiled-demo.nsls2.bnl.gov/api/v1' })`, or pass that URL as
`requestOptions.baseUrl` on a single hook — a public demo server is read-only, so the write hooks
need a server you control.
